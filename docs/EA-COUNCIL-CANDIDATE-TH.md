# ชุดแก้ EA และสภา AI

ชุดนี้แยกจากงานอื่นที่ยังพัฒนาอยู่ โดยเริ่มจาก HQ 0.9.23 และรวมเฉพาะ EA, สภา AI, การแสดงสถานะที่เกี่ยวข้อง และการตรวจตัวติดตั้ง ไม่ได้ติดตั้งทับ HQ หรือเปลี่ยน EA บนกราฟที่กำลังใช้งาน

## เวอร์ชันและไฟล์

| ระบบ | เวอร์ชัน | ไฟล์หลัก |
|---|---|---|
| MT4 Trade Gateway | 2.20 | `integrations/mt4-trade-gateway/MetafxHQTradeGateway.mq4` |
| MT4 binary พร้อมหลักฐาน | 2.20 | `artifacts/mt4-ai-council-ea-v2.18-enum-fail-closed-readiness/MetafxHQTradeGateway.ex4` |
| MT5 Trade Gateway | 1.07 | `integrations/mt5-trade-gateway/MetafxHQTradeGateway.mq5` และ `.ex5` |

ชื่อโฟลเดอร์หลักฐาน MT4 เดิมยังคงไว้เพื่อให้ตัวติดตั้งที่อ้างอิงเส้นทางนี้ทำงานต่อได้ แต่ MANIFEST, Source และ binary ภายในเป็น 2.20 ตัวติดตั้งตรวจเวอร์ชัน ขนาด และ SHA-256 ของไฟล์จริง ไม่เลือกไฟล์จากชื่อโฟลเดอร์อย่างเดียว

## พฤติกรรมที่เปลี่ยน

- MT4 ที่เริ่มต้นไม่พร้อมยังติดอยู่บนกราฟพร้อมสถานะ BLOCKED และไม่ส่งคำสั่งเทรด; การติดซ้ำไม่ลบ state ของ instance ที่ถือสิทธิ์อยู่
- MT5 แสดงเหตุผล Inputs/ราคาไม่สด และแยกหลักฐานการส่งคำสั่งออกจากผลการเปิด/ปิดออเดอร์ รวมถึงต้นทุนในการคำนวณความเสี่ยง
- ผู้วิเคราะห์สภาจองงานคนละรายการก่อนตรวจความพร้อม ลดการแย่งงานแรกกัน โดยยังใช้ deadline, quota, durable claim และ execution guards เดิม
- วิเคราะห์อัตโนมัติเฉพาะแท่งใหม่ที่ทันเงื่อนไข ไม่มีคิวไล่วิเคราะห์แท่งที่พลาดย้อนหลัง เมื่อเริ่มระบบใหม่ให้ตั้ง baseline แล้วรอแท่งถัดไป
- ยกเลิกคิวเก่าที่ค้างสะสมเป็นชุดเดียว ภายใต้ lock และตรวจว่าแต่ละรายการยังตรงกับตอนอ่านไว้ ไม่ทับงานที่ถูกเปลี่ยนหรือเริ่มทำไปแล้ว บันทึก audit แบ่งชุดละไม่เกิน 100 IDs เพื่อไม่ถูกตัดทิ้ง และนับเฉพาะงานที่ยกเลิกจริง
- API สถานะสภาอ่านเฉพาะข้อมูลที่ต้องใช้ และตรวจว่าการเลือก terminal กับ snapshot เป็นชุดเดียวกัน
- Heartbeat ใช้ยับยั้งข้อความ “พร้อมเทรด” ที่ล้าสมัยได้ แต่ไม่เพิ่มสิทธิ์ส่งออเดอร์จากรายงานเดิม
- ตัวติดตั้งตรวจ native compile log และ hash ของ Source/Binary ที่ตรวจแล้ว ปฏิเสธหลักฐานเก่าหรือไฟล์ถูกแก้ ไม่มีการนำภาพคอมไพล์เก่ามารับรองไฟล์ใหม่

## การตรวจและขอบเขต

EA ทั้งสองผ่าน native compilation 0 errors / 0 warnings พร้อมหลักฐานผูกกับไฟล์จริง ทดสอบ source contracts, worker concurrency, deadline/no-backfill, การปฏิเสธคำสั่งซ้ำ, การแสดงผล และการปฏิเสธแพ็กเกจที่ถูกแก้ไขแบบแยกจากระบบเทรด

GitHub Actions ของสาขานี้ตรวจชุด regression บน Python 3.10–3.14 และมีงานทดสอบตัวติดตั้งบน Windows แยกใน RUNNER_TEMP: ติดตั้งใหม่, health, forced rollback และ upgrade ใช้ข้อมูล OAuth จำลองที่ใช้ล็อกอินจริงไม่ได้ และไม่เผยแพร่แพ็กเกจ fixture นั้น ต้องดูผล checks ของ commit ที่จะใช้งาน ไม่ถือว่าการมี workflow เท่ากับรันผ่านแล้ว

**ยังไม่มีหลักฐาน native attach, demo execution หรือ live execution ของ binary ชุดใหม่นี้** ไม่ได้เปิด ปิด หรือแก้ไขออเดอร์ ไม่เปลี่ยนบัญชี/Inputs และไม่รีสตาร์ต terminal บนเครื่องที่ใช้งานอยู่ Compile และ unit tests ไม่ได้ยืนยันพฤติกรรมของทุกโบรกเกอร์

ก่อนใช้กับพอร์ตจริง ให้ทดสอบบนเครื่องหรือ Windows user ที่แยกจากระบบจริง เริ่ม Shadow/Demo ตรวจ attach/restart, Inputs ไม่ถูกต้อง, ติดซ้ำ, ราคาเก่า/เน็ตกลับมา, คำสั่งซ้ำ และหลักฐานผลออเดอร์ก่อน การใช้ `/portable` เพียงอย่างเดียวไม่ได้แยก `FILE_COMMON` ของ Windows user เดิม

การติดตั้งชุดนี้ยังใช้ค่าเริ่มต้น Demo/Read-only และไม่แนบ EA หรือเปิด Algo Trading ให้เอง งาน Sentiment Universe, Full Agent และ EA Factory ที่อยู่นอกสาขานี้ต้องรวมและตรวจแยกก่อนออก release ที่รวมทุกฟังก์ชัน
