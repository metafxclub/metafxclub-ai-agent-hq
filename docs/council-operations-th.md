# สถานะและเหตุการณ์ของสภา AI

เปิด **สภา AI → ประวัติ → สถานะและเหตุการณ์** เพื่อดูว่าแต่ละช่วงมีหลักฐานอะไร สถานะนี้ใช้ประกอบการตรวจปัญหา ไม่ใช่สัญญาณซื้อขายหรือคำสั่งให้เริ่มงาน

## สิ่งที่แสดง

- เหตุการณ์ตามเวลาไทย พร้อมรหัสสาเหตุและแหล่งหลักฐาน: เริ่ม/หยุด Bridge, ช่วงขาดการตรวจ, แท่งที่รับรู้จริง, รอบที่ถูกข้าม และผลการวิเคราะห์
- เหตุที่ยังค้างและเหตุที่กลับมาปกติ โดยรวมการตรวจซ้ำไว้ในเหตุเดียว หากเปลี่ยนไปติดอีกเงื่อนไขจะแสดงว่าเปลี่ยนเงื่อนไข ไม่รายงานว่าระบบกลับมาพร้อมแล้ว
- ความพร้อมจากสถานะที่มีอยู่ ได้แก่การเปิดสภา Terminal ข้อมูลกราฟ Runner โควต้า โหมดทำงาน และรอบก่อนหน้า ข้อมูลเก่าหรือไม่มีหลักฐานเวลาจะไม่แสดงว่าพร้อม
- ปุ่มโหลดประวัติเพิ่มและดาวน์โหลดรายงานตรวจสอบ JSON สำหรับส่งให้ผู้ดูแล

คำว่า **วิเคราะห์ครบ** ต้องมี Technical, Price Action และ News เริ่ม process จริง จบงาน มี vote ถูกโครงสร้าง และอ้างถึง snapshot/digest เดียวกัน การที่สถานะงานแม่เป็น completed/analyzed อย่างเดียวไม่พอ ผล HOLD ถือว่าวิเคราะห์สำเร็จได้ แต่ไม่ได้หมายความว่าต้องเปิดออเดอร์

## อ่านเหตุการณ์อย่างไร

| ข้อความ | ความหมาย |
| --- | --- |
| โควต้าถึงขีดจำกัด | มีผลตรวจยืนยันขีดจำกัดในขณะนั้น |
| อ่านโควต้าไม่ได้ / ข้อมูลเก่า | ยังยืนยันไม่ได้ว่าโควต้าหมด ต้องแยกจากการหมดจริง |
| ช่วงไม่มีข้อมูล | ขาดหลักฐานการตรวจ อาจเป็น Bridge หยุด ค้าง เครื่องปิด หรือเหตุอื่น ห้ามสรุปสาเหตุแทนหลักฐาน |
| ปิด Bridge ตามขั้นตอน | มีบันทึกจาก Bridge ก่อนปิด ไม่ใช่หลักฐานว่า Windows ปิด |
| ประวัติแท่งไม่ครอบคลุม | ไม่ทราบจำนวนแท่งในส่วนที่ขาด ไม่สร้างแท่งสมมติหรือเรียก AI ย้อนหลัง |
| วิเคราะห์บางส่วน | หลักฐานยังไม่ครบสาม role ตรวจแต่ละ role และประวัติการวิเคราะห์เดิมประกอบ |

ปิดแท็บเว็บไม่ได้แปลว่า Bridge ปิด และเมื่อทั้งเครื่องหยุดทำงาน ระบบบนเครื่องไม่สามารถส่งคำเตือนได้เอง จะบันทึกช่วงที่ขาดเมื่อกลับมาทำงาน ศูนย์เหตุการณ์นี้แสดงใน HQ ไม่มีการส่ง Telegram/อีเมลเพิ่ม

## ข้อมูลและขอบเขต

ใช้ Bridge และรอบตรวจเดิม บันทึกหลักฐานลง `data/runtime/council-operations.sqlite3` โดยไม่สร้าง scheduler, provider polling หรือ AI อีกชุด อ่านประวัติด้วย GET เท่านั้น ไม่ refresh โควต้า ไม่สร้าง Mission และไม่อนุญาตส่งคำสั่งไป EA

เก็บเหตุการณ์ใหม่นอกประวัติแบบสั้นเดิมของสภา จึงเปิดดูย้อนหลังได้ แต่ประวัติก่อนติดตั้งรุ่นนี้คืนได้เท่าที่มีหลักฐานเดิมเหลืออยู่เท่านั้น หากพื้นที่เก็บหรือการเขียนมีปัญหา จะแสดงว่าประวัติไม่ครบ ไม่ใช้เหตุขัดข้องนี้ขวางรอบวิเคราะห์ของสภา

รายงานดาวน์โหลดใช้รายการฟิลด์ที่อนุญาต ไม่มี raw log, prompt, Token, รหัสผ่าน, เลขบัญชี, Ticket หรือ path ส่วนตัว รหัสอ้างอิงถูกแปลงเป็น digest และข้อความแปลกปลอมไม่ถูกนำออก รายงานหนึ่งครั้งมีขอบเขตจำนวนรายการ ไม่ใช่สำเนาข้อมูลทั้งเครื่อง

## การทดสอบและอัปเกรด

ทดสอบด้วย snapshot/clock/provider fixtures และ runtime ชั่วคราว รวมถึงโควต้าขาด/หมด ฐานข้อมูลเสีย การเขียนล้มเหลว การ restart การรับแท่งซ้ำ และผลสาม role ไม่ครบ ชุด regression เดิมยังตรวจ Council, Agent, Radar, Sheets, Sentiment, EA contracts และตัวติดตั้ง

การผ่านชุดทดสอบไม่ยืนยันการส่งออเดอร์จริงหรือทุกสภาพแวดล้อมของโบรกเกอร์ การอัปเกรดโปรแกรมจริงต้องทำช่วงบำรุงรักษาที่เจ้าของเครื่องหยุด HQ ตามขั้นตอน ตัวติดตั้งเก็บค่าตั้งเดิมและปฏิเสธการเขียนทับ Bridge ที่กำลังใช้งาน ไม่หยุด MT4/MT5 หรือแก้คำสั่งของออเดอร์เดิม
