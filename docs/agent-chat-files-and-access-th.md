# แชต Agent: ไฟล์และสิทธิ์การทำงาน

หน้าแชต Agent ทุกตัวใช้ระบบแนบไฟล์และสิทธิ์เดียวกัน เลือก **เพิ่มไฟล์ / Add file** แล้วส่งข้อความได้ ไม่ต้องเปิด Full Access เพียงเพื่ออ่านโค้ด MQ4 หรืออ่านข้อความในเอกสาร

## ไฟล์เข้าและผลลัพธ์

- แนบได้สูงสุด 4 ไฟล์ต่อข้อความ ไฟล์ละไม่เกิน 8 MiB
- โค้ด: MQ4, MQ5, MQH, Python, JavaScript, TypeScript, C/C++, Pine และไฟล์ข้อความ/การตั้งค่า เช่น SET, CSV, JSON, XML, YAML, TOML, LOG
- MQ4/MQ5 รองรับ UTF-8 และ UTF-16 ที่มี BOM จาก MetaEditor โดยเก็บต้นฉบับเดิม
- PDF อ่านชั้นข้อความ; PDF ที่เป็นภาพสแกนต้องใช้ภาพหรือเครื่องมือ OCR เพิ่มเติม
- DOCX อ่านข้อความ/ตาราง, XLSX อ่านเซลล์และค่าที่บันทึกไว้โดยไม่คำนวณสูตร, PPTX อ่านข้อความ/บันทึกประกอบ
- ZIP อ่านรายการและเนื้อหาไฟล์ข้อความภายใน โดยไม่รันหรือแตกไฟล์ออกไปยังเครื่อง
- รูป PNG, JPEG และ WebP ส่งให้โมเดลที่รองรับภาพได้โดยตรง
- แชตอ่านเนื้อหาสูงสุด 32,000 ตัวอักษรต่อไฟล์ และ 48,000 ต่อข้อความ หากเกินจะแจ้งให้ใช้ Workspace/Full เพื่ออ่านต้นฉบับต่อ ไม่ตัดเนื้อหาเงียบ ๆ
- โหมด Workspace/Full สามารถสร้างไฟล์ในโฟลเดอร์ผลลัพธ์ของรอบงาน และหน้าแชตแสดงปุ่มดาวน์โหลด/ภาพตัวอย่างจากไฟล์ที่ Backend ตรวจแล้ว
- การแนบไฟล์ไม่ใช่คำสั่งให้รันโค้ด ติดตั้งโปรแกรม หรือเปิดออเดอร์

## สิทธิ์

**Chat** ใช้ตอบและวิเคราะห์ไฟล์โดยไม่เรียกเครื่องมือบนเครื่อง

**Workspace** ใช้เครื่องมือและเขียนไฟล์ภายใน workspace ของแชต การเลือกโหมดเป็นการอนุญาตงานปกติภายในขอบเขตนี้ ไม่ใช่สัญญาว่าจะมีคำถามก่อนเขียนทุกไฟล์

**Full Access** เป็นสิทธิ์ native `danger-full-access` ของ Codex แยกอนุญาตต่อแชตเมื่อผู้ใช้เลือกจริง ระบบเก็บหลักฐานการเลือกและแสดง ON หลัง Backend ยืนยันเท่านั้น โหมดนี้มีสิทธิ์กว้างกว่า workspace และไม่ได้มี sandbox จำกัดอยู่ในโฟลเดอร์นั้น แชตเก่าที่ไม่มีหลักฐานการเลือกจะไม่ถูกยกระดับเอง

การทำงานยังมี Mission, Owner, Audit, การยกเลิก, เวลา/งบงาน และการอนุมัติที่ Codex ร้องขอจริง การเปิด Full Access ไม่ได้เปลี่ยนการตั้งค่า EA หรือปิด Risk Guard ของระบบเทรด

Computer Use, MCP และ Plugin แสดงสถานะการเชื่อมต่อของแต่ละระบบแยกกัน Full Access ไม่ได้แปลว่าเชื่อมต่อทุกบริการแล้ว

## การแสดงผลและการส่งซ้ำ

แสดงข้อความ Markdown, code block และลิงก์ HTTP(S) โดยไม่รัน HTML/JavaScript จากคำตอบ ลิงก์ในคำตอบเป็นลิงก์อ้างอิงจาก Agent ไม่ได้ติดป้ายว่าตรวจสอบข้อเท็จจริงแล้วอัตโนมัติ

คำขอเดิมที่ส่งซ้ำด้วย idempotency key เดิมและไฟล์ชุดเดิมจะคืนรอบเดิม ไม่สร้าง Mission/การเรียกโมเดลซ้ำ การเปลี่ยนข้อความหรือไฟล์ภายใต้ key เดิมจะถูกปฏิเสธ

ไฟล์ที่ดาวน์โหลดใช้รหัสเฉพาะของแชตและรอบงาน ไม่เปิดเผย path ส่วนตัว หน้าแชตยังแสดงชื่อไฟล์ในประวัติหลังไฟล์หมดอายุตามนโยบายคลังไฟล์ และระบุเมื่อดาวน์โหลดไม่ได้แล้ว

## เครื่องนักเรียน

โมดูลอ่านไฟล์และ dependency `pypdf` รวมอยู่ในรายการติดตั้ง/แพ็กเกจ Release พร้อม SHA-256 นักเรียนต้องใช้บัญชี Codex และโควตาของตนเอง ไม่คัดลอก authentication หรือ runtime จากเครื่องผู้สอน การแก้ใน source และเครื่องผู้สอนไม่ได้อัปเดตเครื่องนักเรียนที่ติดตั้งรุ่นเก่าอัตโนมัติ ต้องส่งมอบ Release ที่มีแพตช์นี้ก่อน
