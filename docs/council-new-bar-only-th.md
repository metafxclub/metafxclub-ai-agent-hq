# สภา AI: วิเคราะห์เฉพาะแท่งปิดใหม่

การวิเคราะห์อัตโนมัติรับเฉพาะแท่งที่เพิ่งปิด โดยตรวจโควตา ความพร้อมของระบบ และอายุ Snapshot ก่อนเริ่ม AI เมื่อไม่ผ่านเงื่อนไขหรือพลาดช่วงเริ่ม ระบบบันทึกแท่งนั้นว่า **ข้าม** พร้อมสาเหตุ ไม่สร้างงานวิเคราะห์ย้อนหลัง

- หากโควตาหมดตอนแท่งปิด ระบบข้ามแท่งนั้น เมื่อโควตากลับมาระหว่างแท่งให้รอแท่งปิดถัดไป
- คิวเก่าที่ยังไม่เริ่มจะถูกยกเลิกและแสดงในประวัติว่า “ยกเลิกคิวย้อนหลังตามนโยบายใหม่” ไม่ลบหลักฐานประวัติ
- Snapshot ที่หมดอายุหรือยืนยันเวลาไม่ได้จะถูกข้ามก่อนเรียก AI
- หลังเริ่มระบบใหม่หรือเปลี่ยนกราฟ ระบบตั้งจุดเริ่มและรอแท่งปิดใหม่ ไม่เรียกคิวเดิมย้อนหลัง
- ผลวิเคราะห์และผล Order ที่เกิดขึ้นจริงก่อนเปลี่ยนนโยบายยังคงแสดงตามหลักฐานเดิม รวมถึงรอบเก่าที่เคยวิเคราะห์เพื่อเก็บประวัติ

หน้าเว็บใช้จำนวนงานที่ Backend ยืนยันเพื่อแสดงงานรอ ความต่างระหว่าง “แท่งที่ตรวจพบล่าสุด” กับ “แท่งที่วิเคราะห์ล่าสุด” ไม่ได้หมายความว่ามีงานรอ เพราะแท่งนั้นอาจถูกข้ามไปแล้ว หน้าเว็บไม่คาดเดาเวลาเริ่มรอบจากนาฬิกาเครื่องผู้ใช้

นโยบายนี้ใช้กับการวิเคราะห์อัตโนมัติของสภา AI ไม่เปลี่ยนตาราง Radar หรือ FX28 และไม่ส่งคำสั่งปิดหรือแก้ไขออเดอร์ที่มีอยู่
