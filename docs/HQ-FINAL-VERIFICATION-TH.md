# ชุดตรวจรวม HQ 0.9.24 — 25 ตุลาคม 2569

ชุดนี้ต่อจาก `main` commit `709c835` ซึ่งรวม Sentiment Universe, Agent, Radar และ EA Factory แล้ว แยกการเตรียม source และทดสอบออกจากโปรแกรมที่กำลังใช้งาน ไม่ติดตั้งทับหรือเปลี่ยน EA บนกราฟระหว่างตรวจ

## สิ่งที่แก้

- สภา AI ยกเลิกงานแท่งเก่าที่ค้างเป็นชุดเดียว ตรวจสถานะซ้ำภายใต้ lock นับเฉพาะรายการที่ยกเลิกจริง และบันทึก audit เป็นส่วนย่อยไม่เกิน 100 IDs ไม่ให้ตัวกรองตัดหลักฐานทิ้ง งานที่เริ่มแล้วหรือถูกแก้ระหว่างอ่านจะถูกเก็บไว้
- ลบฟังก์ชันซ้ำที่เกิดระหว่างรวมโค้ด โดยคง implementation ที่มีผลจริงไว้ชุดเดียว พร้อมตรวจ AST ป้องกันนิยามฟังก์ชันทับกันในอนาคต
- ข่าว Sentiment บันทึกเวลาที่อนุญาตให้ลองใหม่ลงดิสก์ก่อนติดต่อแหล่งข่าว หากโปรเซสล้มระหว่างดึงข้อมูลจะไม่ดึงซ้ำทันทีเมื่อเปิดใหม่ ข่าวและเวลาข้อมูลล่าสุดเดิมยังคงอยู่
- การเลือก MT5 เทียบเวลาค้นพบและเวลาปัจจุบันที่ความละเอียด microsecond เดียวกัน แก้กรณี Windows มองรายการที่เพิ่งค้นพบว่าหมดอายุจากการปัดเศษ โดยยังคงปฏิเสธเวลาอนาคต อายุเกิน 600 วินาที และ terminal ที่เปลี่ยนไป
- เพิ่มสัญญา API สำหรับการทำต่อ EA Factory ที่ยกเลิก ให้ตรงกับ backend และ frontend รวมทั้งหลักฐานการทำต่อได้ครั้งเดียว
- ปรับคำอธิบาย no-backfill และฐานคำนวณความเสี่ยง MT4/MT5 ให้ตรงกับโค้ด

## ข้อมูลและการอัปเดต

- Sentiment ใช้ Myfxbook ที่เชื่อมบนเครื่อง ไม่บรรจุรหัสผ่านหรือ session ของผู้ใช้ในชุดติดตั้ง รอบอัปเดตต้องอยู่ภายในโควตาของผู้ให้บริการ
- Correlation อ่านราคา MT5 ของ terminal ที่เลือกและคำนวณในเครื่อง เส้นข้อมูลนี้ไม่ส่งคำสั่งซื้อขาย ปัจจุบันใช้ 30 สินทรัพย์ ส่วน WTI/Brent แสดงไม่มีข้อมูลตามการตั้งค่าที่ตกลงไว้
- ปฏิทินข่าวแปลงวันและเวลาเป็น `Asia/Bangkok` แสดงทุกรายการที่แหล่งข้อมูลส่งมาสำหรับวันนั้น ไม่รับประกันว่าผู้ให้บริการมีทุกเหตุการณ์ทั่วโลก
- ตัวเลข forecast/previous มาจากปฏิทินข่าว คำอธิบายไทยและสถานการณ์ต่ำกว่า/เท่ากับ/สูงกว่าคาดเป็นกฎที่เตรียมไว้ รุ่นนี้ยังไม่ได้เรียก AI วิเคราะห์ข่าวใหม่วันละครั้ง และ feed นี้ยังไม่ส่งผล actual จึงต้องแสดง `aiStatus=not_run` และไม่แต่งผลประกาศขึ้นมา
- หากแหล่งข้อมูลล้าสมัย ตลาดปิด หรือโควตาไม่พร้อม ต้องแสดงสถานะจริง ไม่แสดงข้อมูลตัวอย่างเป็นข้อมูลสด
- Radar ตั้งเวลา 09:00 น. ไทย หากโควตาไม่พร้อมจะรอตามนโยบาย Radar เวลาเริ่มจริงจึงอาจช้ากว่าเวลานัด ส่วนสภา AI ใช้นโยบายต่างกัน: รอแท่งใหม่ถัดไป ไม่มีการวิเคราะห์แท่งที่พลาดย้อนหลัง

## EA สำหรับเครื่องใหม่

| ระบบ | รุ่น | หลักฐาน |
|---|---|---|

MT4 ใช้นโยบาย commission estimate/คำยืนยันบัญชีปลอด commission ตามคู่มือ ส่วน MT5 1.07 คำนวณจากราคาและ slippage ไม่รวม commission/swap

## วิธีตรวจและขอบเขต

GitHub workflow `Verify safe runtime` ตรวจ regression บน Windows/Python 3.10–3.14 และตรวจติดตั้งใหม่, health, rollback เมื่อบังคับให้ล้มเหลว และอัปเกรดใน `RUNNER_TEMP` โดยใช้ OAuth fixture ที่ไม่ใช่บัญชีจริง ดูผลของ commit ปัจจุบันใน PR; ผลของ commit เก่าไม่ใช่หลักฐานของชุดใหม่

การผ่าน compile, unit tests และ installer CI ยังไม่ใช่หลักฐาน native attach หรือส่งคำสั่งซื้อขายสำเร็จบนทุกโบรกเกอร์ ก่อนเปิด Live บนเครื่องใหม่ต้องทดสอบ Shadow/Demo, การเริ่มใหม่, Inputs ที่ไม่ถูกต้อง, reconnect, ราคาล้าสมัย, คำสั่งซ้ำ และ ACK บนเครื่องหรือ Windows user ที่แยกจากระบบจริง การใช้ `/portable` อย่างเดียวไม่ได้แยก `FILE_COMMON`

ค่าเริ่มต้นของชุดติดตั้งยังเป็น Demo/Read-only ไม่แนบ EA เปิด Algo Trading หรือย้ายออเดอร์ให้เอง การตรวจรอบนี้ไม่อัปเดต runtime ที่กำลังทำงานโดยอัตโนมัติ
