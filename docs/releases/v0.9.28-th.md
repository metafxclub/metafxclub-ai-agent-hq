# v0.9.28 — หลักฐานสถานะสภา AI

เพิ่มแท็บ **สถานะและเหตุการณ์** ในประวัติของสภา AI เพื่ออธิบายช่วงที่ไม่มีการวิเคราะห์ โดยแยกโควต้าหมด ข้อมูลโควต้าไม่พร้อม ข้อมูล MT5 เก่า รอบวิเคราะห์ไม่ครบ และช่วงที่ไม่มีหลักฐานการตรวจ

- เก็บเหตุการณ์และประวัติแท่งที่รับรู้จริง พร้อมการแบ่งหน้าและเวลาประเทศไทย
- รวมเหตุซ้ำ แสดงเหตุที่ยังค้างและการกลับมาปกติ
- ตรวจความพร้อมจาก cache เดิม โดยไม่เพิ่มการเรียก Codex หรือ provider
- ดาวน์โหลดรายงาน JSON ที่ตัดข้อมูลส่วนตัวและข้อมูลลับ
- เพิ่มการทดสอบเหตุขัดข้อง: journal เขียนไม่ได้/เสียหาย, cache เก่า, restart/gap, partial votes และการแยก observer ออกจากการรับงานของสภา
- เพิ่มไฟล์ใหม่ในรายการตรวจ Source, Runtime และแพ็กเกจติดตั้ง

ดูวิธีใช้งานและข้อจำกัดใน [คู่มือสถานะสภา AI](../council-operations-th.md)

ไม่มีการเปลี่ยนกฎรับแท่งใหม่ ระยะเวลาวิเคราะห์ นโยบายโหวต ความเสี่ยง หรือการส่งคำสั่งของ EA ไม่มี AI วิเคราะห์ย้อนหลังและไม่มี worker ซ้ำ

เครื่องที่ติดตั้งอยู่แล้วให้ใช้ [Prompt อัปเกรดเก็บค่าตั้งเดิม](../prompts/update-github-preserve-settings-th.md) หลัง release ของรุ่นนี้เผยแพร่และตรวจผ่านแล้ว อัปเกรดเฉพาะช่วงบำรุงรักษา ตัวติดตั้งจะไม่เขียนทับ HQ ที่ยังทำงานอยู่
