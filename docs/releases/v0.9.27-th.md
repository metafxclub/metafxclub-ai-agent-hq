# Metafxclub AI Agent HQ v0.9.27

รุ่นนี้รวมแพตช์แคชชีต ข่าว AI รายวันสำหรับ Forex/ทอง/เงิน และตัวแก้สภา AI ที่ตรวจบนเครื่องผู้พัฒนาแล้ว พร้อมขั้นตอนอัปเกรดที่รักษาค่าตั้งเดิม

## สิ่งที่เปลี่ยน

- แยกงาน Google Sheets ออกจาก Bridge scheduler ด้วย process ที่ Bridge เป็นเจ้าของโดยตรง ทำงานเป็นชุดเล็ก มี deadline/cursor และเก็บสถานะสำหรับทำต่อ ความล้มเหลวของชีตไม่ทำให้ Core Health เสียเพียงเพราะชีตไม่พร้อม
- รีเฟรชแคชชีตเมื่ออายุครบ 24 ชั่วโมง แม้ไม่มีรายงานส่งใหม่ ไม่ปลอมเวลาข้อมูลเมื่อรีเฟรชล้มเหลว
- Sentiment Universe รวมข่าวของวันไทยเป็นงาน AI เดียว ตรวจความพร้อมหลัง 00:10 น. จองสิทธิ์ส่งงานไม่เกินหนึ่งครั้งต่อวัน เก็บ ledger ป้องกันส่งซ้ำหลังรีสตาร์ต/อัปเกรด ไม่สะสมงานวิเคราะห์วันเก่า และให้คิวสภา AI มีลำดับความสำคัญก่อน
- เพิ่มสรุปข่าวภาษาไทย คำอธิบายอ่านเพิ่มเติม แหล่งอ้างอิง และฉากทัศน์ต่ำกว่า/ใกล้เคียง/สูงกว่าคาด สำหรับข่าวตัวเลข USD มีผลกระทบทอง XAUUSD และเงิน XAGUSD แยกกัน
- สภา AI วิเคราะห์ Technical, Price Action และ News แบบขนานภายใต้งบเวลารวม 300 วินาที ตรวจอายุงาน snapshot/digest และผลโหวต ป้องกันงานหมดอายุหรือคิวเก่าถูกใช้เปิดคำสั่ง
- ปรับชุดตรวจ source/archive/installed runtime ให้รวมโมดูลข่าวรายวันและการแสดงผลครบถ้วน

## การใช้งานและอัปเกรด

- ติดตั้งใหม่: ใช้ `docs/prompts/install-github-google-auto-th.md` จาก tag `v0.9.27`
- มีโปรแกรมอยู่แล้ว: ใช้ `docs/prompts/update-github-preserve-settings-th.md` จาก tag เดียวกัน เพื่อรักษา endpoint, โหมด, เป้าหมาย MT4/MT5, Myfxbook, การเชื่อม Google, Mission/Report และ ledger ข่าวเดิม
- การอัปเกรด backend ใช้ช่วงบำรุงรักษาที่เจ้าของเครื่องหยุด HQ ไว้แล้ว ตัวติดตั้งปฏิเสธการอัปเกรดขณะ Bridge เดิมยังรันอยู่ รวมถึงกรณีดูเหมือนว่าง เพื่อไม่ให้ตัดรอบสภาที่อาจเข้ามาระหว่างตรวจ หากตัวตรวจแจ้งว่าระบบยังใช้งานอยู่ ให้เลื่อนการอัปเกรด ไม่ปิดงานหรือเปลี่ยนค่าของผู้ใช้เพื่อข้ามตัวตรวจ ไม่มีการอ้างว่าอัปเกรด backend ได้โดยไม่หยุด HQ
- ไม่มีการติดตั้ง EA ทับกราฟหรือรีสตาร์ต MT4/MT5 อัตโนมัติ EA ที่จัดส่งยังเป็น MT4 v2.20 และ MT5 v1.07 พร้อม source/binary/หลักฐาน compile เดิม
- การติดตั้งใหม่เริ่มในโหมด Demo/Read-only บัญชี Codex/Myfxbook/Google เป็นของแต่ละเครื่อง ต้องเชื่อมด้วยบัญชีของตนเอง

## ขอบเขตข้อมูล

บทวิเคราะห์ข่าวใช้โควตา Codex เมื่อเริ่ม process จริง ไม่ต้องเพิ่ม API key และไม่เปิดใช้เครดิตแบบเสียเงินเพิ่มเติม หาก process ล้มเหลว ถูกยกเลิก หรือเครื่องขัดข้องหลังจองสิทธิ์จนไม่อาจยืนยันว่าเริ่ม process ไปแล้วหรือไม่ จะไม่เรียกซ้ำในวันนั้น หน้าจอแสดงคำอธิบายพื้นฐานและสถานะตามจริง

ปฏิทินแสดงทุกเหตุการณ์ที่ผู้ให้บริการส่งมาของวันไทยนั้น แหล่ง Weekly Export ไม่มี Actual แบบเรียลไทม์และอาจไม่ครอบคลุมการเลื่อนเวลาระหว่างวัน ผลวิเคราะห์เป็นฉากทัศน์ตามเงื่อนไข ไม่ใช่คำสั่งซื้อขายหรือการรับประกันทิศทาง

## หลักฐานก่อนออก release

แพตช์หลักผ่าน 1,195 การทดสอบก่อนเตรียม release และตรวจรอบ XAUUSD H1 ตามธรรมชาติวันที่ 27 ตุลาคม 2569 เวลา 23:00 น. ครบทั้งสามบทบาทภายใน 117.34 วินาที ผลรวม NO_TRADE โดยไม่ได้ส่งคำสั่งทดสอบจริง ออเดอร์สรุปเดิมและ MT5 process ไม่เปลี่ยนระหว่างการติดตั้งแพตช์ในเครื่องผู้พัฒนา

Release ต้องผ่าน Windows CI บน Python 3.10–3.14 และการตรวจแพ็กเกจ/ติดตั้ง/อัปเกรด/rollback เพิ่มเติมก่อนเผยแพร่ ZIP พร้อม SHA-256 ห้ามถือเพียงว่ามี tag หรือมีไฟล์ source เป็นหลักฐานว่าชุดติดตั้งผ่านแล้ว
