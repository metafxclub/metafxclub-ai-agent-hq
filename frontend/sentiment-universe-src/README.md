# Metafxclub — Sentiment Universe

หน้า WebGL สามมิติสำหรับ **32 สินทรัพย์ในกาแล็กซี 9 กลุ่ม** สร้างด้วย React, Vite และ Three.js ปัจจุบันหน้าหลักอ่านข้อมูลจากบริการ local จริง: Myfxbook Community Sentiment, correlation จากแท่ง MT5 และปฏิทิน Forex Factory ไม่ใช้ข้อมูลตัวอย่างทดแทนเมื่อแหล่งข้อมูลยังไม่พร้อม และไม่มีคำสั่งซื้อขายในหน้านี้

HQ รวมหน้าเดียวกันไว้ในอุปกรณ์ `left_signal_cube` ด้วย ShadowRoot ไม่ใช้ iframe และไม่เปลี่ยน ID อุปกรณ์ สถานะของแต่ละแหล่ง เวลาเก็บข้อมูล และจำนวนสินทรัพย์ที่มีข้อมูล แสดงแยกกัน การเปิดหน้าได้ไม่ได้แปลว่าข้อมูลครบทั้ง 32 รายการ ดูรายละเอียดใน [LOCAL-DATA-SETUP.md](LOCAL-DATA-SETUP.md)

## ความหมายของภาพ

- **สีดาว** คือสัดส่วน Long/Short ของชุมชน Myfxbook ไม่ใช่ทิศทางราคา หรือโอกาสชนะ สีเทาหมายถึงไม่มีข้อมูลที่ใช้ได้
- **เส้นเชื่อม** คือ Pearson correlation ของผลตอบแทนราคาปิด H1 จาก MT5 ที่มีช่วงเวลาตรงกัน แสดงเฉพาะค่าที่คำนวณได้ ค่าใกล้ศูนย์ต่างจากข้อมูลที่ขาด
- **แสงวิ่ง ฝุ่นดาว และโมชั่น** เป็นภาพประกอบ ไม่ใช่การส่งออเดอร์หรือการยืนยันว่ามีข้อมูลใหม่ทุกเฟรม
- **ข่าว** เป็น snapshot ปฏิทินจาก Forex Factory แสดงเวลาไทย เก็บหลายข่าวในเวลาเดียวกัน และรวมทั้งสองสกุลเงินเมื่อเลือกคู่ Forex แหล่งนี้ไม่ส่งผลจริงของตัวเลขประกาศ
- **ตำแหน่ง ระยะห่าง และแกน 3D** ใช้จัดองค์ประกอบ ไม่ได้แทนราคา ปริมาณซื้อขาย หรือความเชื่อมั่น

## สินทรัพย์และกลุ่ม

| กลุ่ม | จำนวน |
| --- | ---: |
| EUR | 7 |
| GBP | 6 |
| AUD | 5 |
| NZD | 4 |
| USD | 3 |
| CAD | 2 |
| CHF | 1 |
| Metals — XAUUSD, XAGUSD | 2 |
| Oil — WTI, BRENT | 2 |

Forex 28 คู่จัดเพียงกลุ่มเดียวตามลำดับ EUR → GBP → AUD → NZD → USD → CAD → CHF จึงไม่มีดาวซ้ำ ทองคำ เงิน และน้ำมันอยู่ในกลุ่มของตนเอง จำนวน 32 คือจำนวนรายการที่รองรับ ไม่ใช่คำรับรองว่าทุกโบรกเกอร์หรือ provider มีข้อมูลครบ รอบตรวจเครื่องผู้สอนวันที่ 24 ตุลาคม 2026 มี MT5 30 สินทรัพย์และยังไม่มี WTI/BRENT ที่ใช้ได้ เครื่องอื่นต้องตรวจ coverage ของตัวเอง

## พัฒนาและ build

ใช้ Node.js และ pnpm โดยคง `pnpm-lock.yaml` สภาพแวดล้อมที่ build รอบนี้ใช้ Node 24.19.0 / pnpm 11.25.0 จากโฟลเดอร์นี้:

```powershell
pnpm install --frozen-lockfile
pnpm build
pnpm build:hq
pnpm test
```

- `dist/client`: หน้า standalone สำหรับบริการ local พอร์ต 4197
- `dist/hq-embed`: `sentiment-universe.js` และ assets สำหรับ HQ; ส่งออก `mountSentimentUniverse(host, options)` และคืน `{unmount()}`
- Build ไม่เริ่ม collector ไม่เชื่อม provider และไม่แก้ระบบที่ติดตั้งอยู่
- `pnpm preview` ตรวจ UI แบบ static เท่านั้น ไม่มี `/api/market` หรือ `/connect` จึงไม่ใช่บริการข้อมูลจริง ห้ามเปิดแย่งพอร์ต 4197 กับบริการที่ทำงานอยู่
- ใน canonical HQ source โค้ดนี้อยู่ที่ `frontend/sentiment-universe-src` และขั้นตอน build/copy อยู่ใน `docs/sentiment-universe-frontend-build.md`

อย่าคัดลอก `%LOCALAPPDATA%/Metafxclub/SentimentUniverse`, credential, DPAPI, cache, log หรือ `market.json` ของผู้สอนไปในแพ็กเกจนักเรียน

## ประวัติการออกแบบ — ไม่ใช่การคำนวณปัจจุบัน

ต้นแบบเดิมชื่อ Market Universe ใช้แนว **Constellation Archipelago**: กาแล็กซี 9 กลุ่ม หมอกเนบิวลาหลายชั้น ดาวเคลื่อนอิสระ และแผงรายละเอียดด้านข้าง องค์ประกอบเหล่านี้ยังเป็นพื้นฐานของภาพปัจจุบัน

ก่อนเชื่อมข้อมูลจริงเคยทดลอง **Precision Atom** เป็นวงโคจรไขว้สามระนาบแทน M15–H1, H1–D1 และ D1–W1 พร้อมทิศทางและกราฟจำลอง ไฟล์ตัวอย่างบางชุดยังเก็บไว้สำหรับทดสอบ geometry/งานออกแบบ แต่หน้าหลัก `src/main.jsx` ใช้ `AppSentiment` และ `market-data.js` เท่านั้น ไม่ใช้วงแหวนเดิมเป็นผลวิเคราะห์แนวโน้มจริง ข้อเสนอเก่าใน [integration-preparation.md](integration-preparation.md) เป็นประวัติการออกแบบ ไม่ใช่สัญญาการทำงานปัจจุบัน
